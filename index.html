TheChartSpark

Music Stat Visualization Discord Bot

TheChartSpark is a Discord bot developed to assist with visualizing music industry data, serving a chart community of over 4,000 members, with commands used over 36,000+ times.

Spotify Daily Chart Commands

24/7 Spotify Chart Commands allowing one to view daily chart data, for the current date, or any date in the past. All commands are paginated, splitting long data into multiple pages, enabling one to view all data available for the given command.

Top Countries

Display all regions a song is charting in

Top Artist Songs

Display the top songs by an artist in a given region/worldwide

Top Regional Songs

Display the chart of a given region/worldwide

Top Regional Highlights

Display the highlights of a regional or worldwide chart, including New Peaks, Re-Entries, Top Gains, Top Losses and dropouts

Artist Summary- Songs

Display a summary of all songs by an artist that are charting on a day

Artist Summary - Regions

Display a summary of all regions an artist is charting songs in

Spotify Historical Chart Commands

Like the daily chart commands, except these commands don't just focus on a single day, they summarize the entire history of the charts.

Artist History

Display all songs by an artist that have charted in a given region, or worldwide.

Song History

Display all regions a given song has ever charted in

Chart Run

Display the chart run of a given song in a given region, or worldwide.

Total Summary

Display all songs by an artist that has charted anywhere, sorted by the number of regions charted

Cumulative Chart

Display a cumulative chart from a given date range in a given region or worldwide, for example, a year-end chart

Counter Streams

Display of raw, unfiltered, total stream count of an album/track

Spotify Mail List Updates

Allows for users in the community to sign up for a customized daily mail experience. Every day, users receieve dms with all features signed up for.

Apple Music Live Chart Updates

Posts realtime updates for Apple Music Charts to the channel. Updates in real-time, as soon as the charts update.
Visualizes significant changes in song movements, new all-time positional peaks for songs, along with updates for featured new album releases.

YouTube Daily Chart Updates

Posts daily updates for YouTube Music Videos and Song charts worldwide and of various regions, as soon as YouTube updates.

US Radio Daily Chart Updates

Posts daily updates for US Radio charts, for 10+ radio genres, along with an overall summary as soon as MediaBase updates.

Billboard Weekly Chart Updates

Posts weekly billboard updates for over 30+ billboard charts across many genres as soon as Billboard updates.
